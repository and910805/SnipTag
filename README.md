# SnipTag

本機執行的截圖工具。操作邏輯照著 Snipaste（F1 框選、F3 釘圖、複製到剪貼簿），
但多了一個為「開會連續截圖」設計的功能：

**先設定主題，之後每張截圖直接存成 `MDASH_01.png`、`MDASH_02.png`、`MDASH_03.png`…
完全不跳存檔對話框、不用命名。**

## 安裝

需要 Python 3.10 以上。

```bash
pip install -r requirements.txt
```

## 啟動

```bash
python -m sniptag
```

或直接雙擊 `run.bat`（用 `pythonw` 啟動，不會留一個黑色 console 視窗）。

啟動後常駐在系統匣，右鍵圖示可以叫出所有功能。

### 開機自動啟動

按 `Win+R` 輸入 `shell:startup`，把 `run.bat` 的捷徑丟進去即可。

## 熱鍵

| 熱鍵 | 功能 |
| --- | --- |
| `F1` | 框選截圖，放開滑鼠後出現工具列 |
| `Shift+F1` | 快速截圖：放開滑鼠**直接存檔**，不出工具列 |
| `F3` | 把剪貼簿裡的圖釘到桌面 |
| `Ctrl+F1` | 切換主題（換一場會議、換一個題目） |

熱鍵可在「設定…」裡改。如果 Snipaste 也開著會搶走 `F1`，SnipTag 啟動時會跳通知告訴你哪個熱鍵註冊失敗。

## 框選中可用的操作

| 操作 | 說明 |
| --- | --- |
| 拖曳 | 框出範圍 |
| 直接點一下 | 選取游標底下的整個視窗（自動偵測邊界） |
| 拖曳邊角 / 中間 | 框好之後還能調整大小、整塊搬移 |
| `Ctrl+A` | 選取整個桌面 |
| `Enter` 或 `S` 或雙擊 | 自動命名存檔 |
| `Ctrl+C` | 複製到剪貼簿 |
| `F` | 釘到桌面 |
| `Ctrl+S` | 另存新檔（會跳對話框） |
| `Esc` | 取消 |

左下角的放大鏡會顯示游標座標與該點色碼，方便對齊。

## 釘圖視窗

| 操作 | 說明 |
| --- | --- |
| 拖曳 | 移動 |
| 滾輪 | 縮放 |
| `Ctrl` + 滾輪 | 調透明度 |
| `Ctrl+0` | 回到原始大小與不透明 |
| 右鍵 | 存檔 / 另存 / 複製 / 關閉 |
| 雙擊、中鍵、`Esc` | 關閉 |

## 命名規則

檔名樣板預設是 `{topic}_{n:02d}`，可在設定裡改。可用欄位：

| 欄位 | 範例 |
| --- | --- |
| `{topic}` | `MDASH` |
| `{n}` | 流水號。`{n:02d}` → `01`、`{n:03d}` → `001` |
| `{date}` | `20260812` |
| `{date2}` | `08-12` |
| `{time}` | `143005` |
| `{datetime}` | `20260812_143005` |

幾個常見組合：

- `{topic}_{n:02d}` → `MDASH_01.png`
- `{date2}_{n:02d}` → `08-12_01.png`（用日期當主題）
- `{date}_{topic}_{n:03d}` → `20260812_MDASH_001.png`

**流水號是掃描資料夾算出來的，不是記在設定檔裡。** 所以：

- 換主題 → 新主題自動從 `01` 開始
- 關掉程式再開 → 接著原本的號碼往下走，不會從頭覆蓋
- 手動刪掉中間某張 → 不回填空號，永遠接在最大號後面，不會蓋掉既有檔案

「每個主題各開一個子資料夾」打開後，會存成 `<存檔資料夾>/MDASH/MDASH_01.png`。

## 多螢幕與 DPI

支援混合 DPI —— 例如筆電 200% 縮放搭配外接螢幕 100%。程式會把每台螢幕的
邏輯座標、實體像素、縮放比各自對應（用 Windows 的顯示裝置名稱配對），
所以插拔外接螢幕不需要任何設定：

- 每張截圖都以該螢幕的**原生解析度**存檔，不會糊掉也不會被放大
- 框選範圍跨越兩台螢幕時，以較高解析度那台為基準拼接
- 視窗自動偵測在兩台螢幕上都對得準

## 設定檔位置

`%APPDATA%\SnipTag\config.json`

## 測試

```bash
python test_naming.py
```

```bash
python test_dpi.py
```

`test_dpi.py` 用模擬的螢幕組態（筆電 1440x900@200% + 外接 1920x1080@100%）
驗證座標換算，不需要真的接上外接螢幕。
